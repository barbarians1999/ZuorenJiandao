## 这一版的主要变化

- Windows 顶部边框、拖拽区和窗口按钮统一为深色，移除原生 File/Edit/View/Window 菜单。
- 首页聚焦三个常用入口：简单剪辑、添加背景音乐、粘贴文字稿生成字幕。
- 背景音乐入口直接打开本机音频素材，可导入 MP3/WAV、拖入音轨，并调整音量和淡入淡出。
- 新增“粘贴完整文字稿”字幕：先用本机转写取得时间，再用粘贴稿替换显示文字；按约 20 字分句，并生成独立字幕轨。
- 粘贴稿字幕会跟随口播轨的剪切、移动、变速和气口调整；生成后仍可手动改字、时间和样式。
- 新字幕默认使用离线打包的思源黑体（`Noto Sans SC`）、黑字白边、整句显示。
- 保留多轨时间线、波形、片段移动和裁切、转场、变速、画面裁剪/缩放/旋转、透明度、音量和淡入淡出。

## 字幕使用方法

1. 导入口播视频或音频并完成基础剪辑。
2. 对口播运行本机转写，使时间线上已有识别时间。
3. 打开“字幕”，选择整条口播轨，粘贴完整文字稿。
4. 点击“生成独立字幕轨”，重点检查开头、中段和结尾。
5. 在时间线或字幕面板继续修改文字、出现时间和样式。
