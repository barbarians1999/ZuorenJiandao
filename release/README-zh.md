## 首次使用

1. 启动后在“设置 → 存储”选择工程目录。建议工程、视频、音频和导出文件放在同一个专用文件夹，便于备份。
2. 导入 MP4、MP3 或 MOV 素材，拖入时间线后即可剪辑。保存工程，再关闭并重开可恢复上次状态。
3. 需要字幕时，在“设置 → 转写 → 本地模型”下载 Tiny、Base 或 Small。转写在本机 Whisper 运行，不上传原始音频；正式中文口播建议 Base/Small，并人工校对专有名词、数字和近音字。

## 两人交接工程

1. 编辑者 A 保存工程，在工程菜单导出完整工程包。
2. 将工程包和仍在包外的大型原始素材一起交给编辑者 B；包内已纳入的素材、时间线、字幕、MG 描述和 Codex 对话状态会随包传输。
3. B 导入工程包后会得到新的本地工程 ID，不会覆盖已有工程。修改完成后导出新包传回 A。
4. 用日期或版本号命名每次工程包，保留上一版作为可回退快照。

## 已实现的主要功能

- 多轨时间线、波形、移动和裁切片段、转场、变速、裁剪/缩放/旋转、透明度、音量和淡入淡出。
- 1080p 横屏编辑与 MP4、MP3、MOV 素材导出。
- 本机 Whisper 字幕、字幕文字与样式手动修改；默认方案支持思源宋体、黑字白边和约 20 字单行字幕。
- Codex 对话编辑、自动剪辑、口播气口和 MG 共用同一时间线及 `SHxxx` 分镜编号。
- MG 文字、数字、流程图、箭头、柱状图、地图、图标、图片运动；可用鼠标调整运动路径和关键帧，也可让 Codex 修改同一动画。
- 素材、重录口播和 MG 替换；工程保存、恢复、撤销重做和两人往返传输。
- 应用默认不启用上游自动更新；网络服务需用户明确配置，原始视频和音频尽量保留在本机。

## 当前限制

- 安装包没有商业代码签名证书，Windows 可能显示 SmartScreen 提示。
- 当前 Codex 受控执行环境的 `CreateProcess` 策略拦截了安装器启动，因此本轮没有伪称完成真实安装/卸载；最终应用负载已通过同批次 `win-unpacked` 完整渲染冒烟。
- 本地字幕模型首次需要下载；安装包只携带经哈希核验的 Whisper 运行时，不携带数百 MB 至 1 GB 的模型。
- Tiny 适合低配置和快速草稿；正式中文口播应使用 Base/Small 并人工检查。
- 0.2.15 尚未重新跑 40 分钟完整工程；需要长片交付时请先用短片段检查素材、字幕和导出目录。
